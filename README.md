# alshuaibi-family

بوابة المؤشرات المالية وسجل المساهمين — أسرة الشعيبي بالأحساء.

- الصفحة: `index.html` (صفحة واحدة تُنشر عبر GitHub Pages).
- البيانات: تُقرأ وتُحفظ في ملف Google Sheets «بوابة أسرة الشعيبي بالأحساء» عبر Apps Script، لذلك تحديث البيانات من وضع المدير لا يحتاج تعديل هذا المستودع.
- يُعدَّل هذا المستودع فقط عند تغيير تصميم البوابة أو ميزاتها.

## بوابة المسابقات «تحدّي العقول» — `quiz/`

- الصفحة: `quiz/index.html` — مسابقة بين فريقين (حتى 6 أعضاء لكل فريق)، بوضعين: «الجولات السريعة» و«لوحة التحدي».
- بنك الأسئلة (1000 سؤال في 9 فئات، بعضها مدعوم بصور أعلام وخرائط وألغاز إيموجي) محفوظ **مشفّرًا** في `quiz/bank.js` (AES-256-GCM، والمفتاح مشتق من رمز الدخول بـ PBKDF2). لا يمكن قراءة الأسئلة دون رمز دخول من المالك.
- الصفحة لا تعمل إلا من نطاق الموقع الرسمي (`aalshuaibi1983.github.io`).
- رموز الدخول **لا تُحفظ في المستودع**.

### تعديل الأسئلة أو تغيير رموز الدخول
```bash
node tools/quiz-export.mjs <الرمز-الحالي> questions.json     # فك التشفير للتعديل
node tools/quiz-build.mjs questions.json <رمز1> [رمز2 ...]    # إعادة التشفير بالرموز الجديدة
```
لا ترفع `questions.json` إلى المستودع (مستثنى في `.gitignore`).
