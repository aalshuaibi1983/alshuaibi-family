# alshuaibi-family

بوابة المؤشرات المالية وسجل المساهمين — أسرة الشعيبي بالأحساء.

- الصفحة: `index.html` (صفحة واحدة تُنشر عبر GitHub Pages).
- البيانات: تُقرأ وتُحفظ في ملف Google Sheets «بوابة أسرة الشعيبي بالأحساء» عبر Apps Script، لذلك تحديث البيانات من وضع المدير لا يحتاج تعديل هذا المستودع.
- يُعدَّل هذا المستودع فقط عند تغيير تصميم البوابة أو ميزاتها.
